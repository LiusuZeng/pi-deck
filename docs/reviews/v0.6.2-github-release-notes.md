# Pi Deck v0.6.2

## Highlights

- **Completed Work is now durable.** Finished sessions remain in Work across app relaunch and saved-session rehydration, preserving the completion timestamp used by the follow-up queue (#25).
- **Real Pi behaves more like terminal Pi.** Pi Deck now captures the login-shell environment for real workers so PATH-dependent non-interactive tools can run with the same local setup (#38).
- **Usage is more trustworthy.** Session-level real-Pi usage now maps current Pi session statistics (#27), while workspaces gain durable token and reported-cost accounting across normal and private Parallel work (#21).
- **Work is simpler and more consistent.** Pending is now Queued, Idle is removed from operational Work, and All Work counts use one meaning everywhere (#22, #24).

## Work and workspaces

- Added durable workspace token and reported-cost accounting with attribution across sessions, Parallel workers, archive/move, and relaunch behavior (#21).
- Renamed Pending to **Queued** and removed Idle from the operational Work surface (#22).
- Made workspace ownership visible and selectable inline while creating a New Session, without adding a blocking workspace picker (#23).
- Made All Work totals consistent across sidebar/navigation, scope selection, and Work filters (#24).
- Preserved Completed Work across app relaunch and saved-session rehydration, including stable completion timestamps for queue ordering (#25).

## Sessions and activity

- Refined Agent activity into a more semantic execution narrative while retaining lower-level tool/tool-output detail on demand (#18).
- Made bare `http(s)` and `mailto:` URLs clickable in assistant-visible text and tool details, with safe scheme handling and no autolinking inside code (#28).
- Fixed fresh real-Pi session usage metering so reported context/tokens/cache/cost update instead of remaining at zero (#27).
- Accepted fire-and-forget Extension UI methods such as `setWidget` without showing misleading Diagnostics (#36).

## Parallel and runtime reliability

- Allowed private Parallel task sessions to start and continue while the parent session is busy running a command (#32).
- Added login-shell environment capture for real Pi workers, restoring PATH/environment parity for normal non-TTY terminal tooling without weakening Electron renderer sandboxing (#38).

## Identity

- Added Pi Deck's own three-card application/Dock icon and removed default Electron branding (#26).

## Validation

The product code was frozen at `456526328848ef8f184c34c870150e183ab03f3e` before release preparation.

The release-preparation branch must pass hosted **Verify desktop app** CI. After merge, the exact `main` commit must pass:

```bash
npm run verify:release
```

That release gate includes formatting, typechecks, unit/integration tests, production build, site/version validation, deterministic Electron E2E, and the authenticated real-Pi smoke suite.

Only the exact green merged-main SHA should be tagged `v0.6.2`.

## Remaining v0.6.x dogfood backlog

This patch intentionally does not wait for the remaining open dogfood work, including model-picker identity (#30), Agent Workflows workspace-switcher clipping (#35), code-language rendering (#37), command stdout/stderr detail (#41), session rename (#42), streaming Agent activity scroll stability (#43), and optional attention/completion sounds (#44).
