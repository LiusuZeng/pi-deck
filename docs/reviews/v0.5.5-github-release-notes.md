# Pi Deck v0.5.5

## Highlights

- Parallel mode now deterministically plans prompts into one or more private task sessions instead of relying on parent-model tool election.
- The parent stays usable while a flat, private-status panel shows live task clocks, safe major-step progress, attempts, queueing, and terminal outcomes.
- Up to 10 task sessions run per parent; excess work queues, failures retry three times after the initial attempt, and the parent synthesizes successful and failed handoffs.

## Fixed

- Parallel submissions are acknowledged immediately while planning and cannot be accidentally submitted twice.
- Worker model choices remain selected; model-specific thinking resets atomically without reverting to the persistent default.
- Markdown pipe tables render semantically and scroll on narrow layouts.
- The legacy model-visible `deck_delegate` compatibility tool is disabled by default, preventing ordinary prompts from bypassing deterministic planning or becoming stranded on legacy limits.
- Private planner/task workers use `--no-session`; private session files, transcript content, raw tool output, and attachment payloads do not enter navigation or durable task state.
- Referenced files and images are materialized once through validated main-process ownership without persisting selection tokens or image payloads.
- Restarted parents preserve interrupted task trace but never automatically resume unfinished private work.
- Compatibility chat creation without an explicit workspace is assigned to the stable default workspace without changing the active named workspace.
