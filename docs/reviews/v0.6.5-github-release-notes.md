# Pi Deck v0.6.5

Dogfood stabilization patch with a manual Outputs MVP and broad desktop reliability hardening.

## Highlights

- **Save and revise useful answers.** The manual text Outputs MVP can save a completed visible assistant response without another model call, search verified title/body content across workspaces, preserve immutable revisions, and prepare a follow-up session with the selected output and feedback attached. Automatic agent publication and arbitrary multi-file outputs remain future work ([#141](https://github.com/LiusuZeng/pi-deck/issues/141), [#177](https://github.com/LiusuZeng/pi-deck/pull/177)).
- **Find and branch work more easily.** Work now has scoped search and deterministic triage ordering, Workspace Work can create a scoped session directly, and eligible idle Pi sessions can be forked without modifying the source session ([#118](https://github.com/LiusuZeng/pi-deck/pull/118), [#123](https://github.com/LiusuZeng/pi-deck/pull/123), [#124](https://github.com/LiusuZeng/pi-deck/pull/124)).
- **See delegated progress without exposing private work.** Parallel workers and ordinary extension subagents now project bounded read-only phase, recency, turn/token, and terminal information into the parent experience without exposing child prompts, arguments, thinking, raw output, or controls ([#120](https://github.com/LiusuZeng/pi-deck/pull/120), [#139](https://github.com/LiusuZeng/pi-deck/pull/139)).
- **Recover more safely.** Quit confirmation and worker cleanup, renderer recovery, attached-session hydration, pending Extension UI, settings writes, workspace selection, and bounded text drafts now survive more shutdown, reload, crash, and rejection boundaries without duplicate workers or automatic prompt replay ([#158](https://github.com/LiusuZeng/pi-deck/pull/158), [#195](https://github.com/LiusuZeng/pi-deck/pull/195), [#205](https://github.com/LiusuZeng/pi-deck/pull/205)).
- **Keep durable state and accounting honest.** This release adds shared-metadata ownership and recovery, preserves workspace/project/Parallel state through filesystem failures, avoids counting copied fork history twice, and includes private planning work in workspace usage ([#178](https://github.com/LiusuZeng/pi-deck/pull/178), [#184](https://github.com/LiusuZeng/pi-deck/pull/184), [#185](https://github.com/LiusuZeng/pi-deck/pull/185), [#191](https://github.com/LiusuZeng/pi-deck/pull/191), [#193](https://github.com/LiusuZeng/pi-deck/pull/193), [#199](https://github.com/LiusuZeng/pi-deck/pull/199), [#201](https://github.com/LiusuZeng/pi-deck/pull/201)).
- **Harden Pi and workflow lifecycle boundaries.** Workflow retry/synthesis, intervention and prompt delivery receipts, model/session discovery, RPC framing and failure cleanup, stalled Extension UI replies, timeline ownership, and macOS runtime preparation all receive deterministic fixes and regression coverage.

See the [full changelog](https://github.com/LiusuZeng/pi-deck/blob/v0.6.5/CHANGELOG.md) for the complete list of changes and linked issues.

## Validation

GitHub CI is the authoritative routine validation gate. The release-preparation branch and exact merged-main candidate must pass the protected **Verify desktop app** check.

Before tagging, the exact clean `main` candidate must also pass:

```bash
PI_DECK_PI_BINARY=<isolated-pi-0.85.0>/bin/pi npm run verify:release
```

That release gate includes formatting, typechecks, unit/integration tests, production build and deep build validation, site validation, real Pi RPC smoke, deterministic Electron E2E, and the authenticated real-Pi smoke suite.

Only the exact protected-CI-green and authenticated merged-main SHA should receive the annotated `v0.6.5` tag.

## Current boundaries

- Outputs are manually saved, immutable text deliverables; this release does not add automatic agent publication or arbitrary multi-file outputs.
- Draft recovery is bounded and text-only. Attachment authority is not persisted, and uncertain sends require explicit recovery rather than automatic replay.
- Pi Deck cannot reconnect to a previous RPC subprocess after an Electron main-process crash; durable Pi sessions can be reopened, but incomplete streamed output may be lost.

## Distribution

This remains a source-only macOS pre-release. It does not include a packaged, signed, or notarized macOS installer and is not published to npm.
