# Pi Deck v0.6.4

Small dogfood stabilization patch after v0.6.3.

## Highlights

- **Streaming Agent activity stays pinned when it should.** Timeline bottom-follow now survives streaming layout changes, so active tool and output streams do not bounce away from the latest content ([#43](https://github.com/LiusuZeng/pi-deck/issues/43), [#92](https://github.com/LiusuZeng/pi-deck/pull/92)).
- **Manual reading intent remains respected.** Explicit wheel, touch, keyboard, and scrollbar interaction can suspend bottom-follow while the user reads earlier timeline content.
- **Release smoke cleanup is less flaky.** Authenticated real-Pi UI smoke tests retry transient temporary-directory cleanup races after Electron exits, avoiding hosted macOS `ENOTEMPTY` teardown failures without changing application behavior ([#91](https://github.com/LiusuZeng/pi-deck/pull/91)).

## Validation

GitHub CI is the authoritative routine validation gate. The release-preparation branch and exact merged-main candidate must pass the protected **Verify desktop app** check.

Before tagging, the exact clean `main` candidate must also pass:

```bash
npm run verify:release
```

That release gate includes formatting, typechecks, unit/integration tests, production build and deep build validation, site validation, real Pi RPC smoke, deterministic Electron E2E, and the authenticated real-Pi smoke suite. The streaming follow and manual-scroll regression paths are additionally repeated as focused validation without weakening the transient-bounce assertion.

Only the exact green and authenticated merged-main SHA should be tagged v0.6.4.

## Distribution

This remains a source-only macOS pre-release. It does not include a packaged, signed, or notarized macOS installer and is not published to npm.
