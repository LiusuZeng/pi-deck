# Pi Deck v0.6.0

## Highlights

- Unified Work makes supervision a stable primary surface: **All Work** shows saved work across workspaces, scoped Work narrows it to one workspace, and session drill-in returns with **Back** to the originating scope.
- Workspace selection is optional. Pi Deck opens at All Work, while sessions created without an explicit workspace receive stable default-workspace ownership without taking over a selected named workspace.
- Sessions retain their canonical identity and live runtime state across workspace navigation, including cross-workspace sidebar resume.

## Fixed

- Parallel planner and task sessions remain private implementation details: only their durable parent appears in the sidebar, All Work, and scoped Work.
- Parallel synthesis now restores the canonical parent title structurally from Pi session metadata rather than relying on heuristic cleanup.
- Work retains filter, focus, and scroll context independently for each scope; when a retained row is unavailable, the visible heading receives focus instead.
- Waiting-input flows reject unsafe mutations, and fake workspace draft-backend handling now preserves correct workspace ownership.
- Documentation and product screenshots now cover Unified Work, workspace ownership, and real local Pi workflow and Parallel captures.
