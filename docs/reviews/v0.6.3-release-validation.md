## Parallel task-session acceptance

The deterministic and authenticated suites together confirmed the release
contract:

- Parallel Off routes prompts to the parent; Parallel On defaults to New task
  session with an explicit Work in parent override.
- Production routing performs model-backed planning before creating private
  task sessions; it does not depend on `deck_delegate` tool election.
- Multiple task sessions run or queue within the configured bound, remain
  parent-facing only, and do not leak into sidebar or Work rows.
- The flat task panel reports task status while the parent remains usable.
- Attachments are materialized without persisting private payloads.
- Terminal task results are synthesized into the parent.
- Restart preserves interrupted trace without resuming unfinished private work.
- Workspace/archive lifecycle guards and renderer projections are exercised by
  the deterministic acceptance suite.

## Failed-run review and disposition

Two pre-candidate local release attempts produced retained Playwright
screenshots, traces, and error context. Both were inspected rather than retried
without diagnosis:

1. The offscreen-history assertion rejected an exact half-CSS-pixel bottom
   offset even though the final row intersected the viewport. PR #88 replaced
   the strict floating-point boundary with a one-CSS-pixel tolerance and passed
   10 focused repetitions plus protected CI.
2. The real command-detail test took a one-shot DOM snapshot before async tool
   details settled. Its failure screenshot already showed Command, Output, Exit
   status, stdout, and stderr correctly rendered. PR #89 replaced the snapshot
   with web-first polling and passed two focused authenticated repetitions plus
   protected CI.

The final candidate had no failed or retried test. Its passing Playwright report
contained no failure screenshots or traces requiring further disposition.
