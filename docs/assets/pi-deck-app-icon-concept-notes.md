# Pi Deck app icon concept

Visual direction captured from the 2026-08-25 dogfood/design session.

Preferred concept:

- a literal **deck of three cards** as the identity;
- no π glyph;
- no UI/status/badge marks on the front card;
- front card off-white, middle card blue, rear card slate/dark;
- simple fan/offset silhouette that remains recognizable at Dock/sidebar sizes;
- dark rounded macOS-style app-icon container;
- identity should come from the deck silhouette itself, not printed content.

The companion SVG in this folder is a repo-hosted vector capture of the chosen concept so the visual direction is not dependent on the chat transcript.
